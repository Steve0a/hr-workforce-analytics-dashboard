# Project Overview

## Summary

The HR Workforce Analytics Dashboard is an interactive Tableau project designed to make workforce data easier to explore and communicate. It combines departmental activity, job roles, demographics, education, compensation, and location views into a single analytics experience.

## Objective

Create an accessible dashboard that enables users to explore workforce composition and HR activity patterns in support of workforce planning, compensation review, engagement analysis, diversity monitoring, and retention discussions.

## Scope

The dashboard includes views for:

- Department-level hiring and termination activity
- Job-title distribution
- Headquarters and branch workforce distribution
- State and city-level geographic mapping
- Gender and age-group views
- Education-level distribution
- Average salary comparisons by age, role, education, and gender

## Data Preparation

The project materials describe a preparation process that included:

- Reviewing missing values in salary, performance-rating, hire-date, and termination-date fields
- Standardizing selected categorical values
- Converting relevant date values to a consistent format
- Deriving age and employment-duration measures
- Creating salary bands and performance-related indicators for analysis

## Intended Audience

This portfolio project is intended for recruiters, analysts, product and business stakeholders, and learners who want to review an example of Tableau-based HR analytics and data storytelling.

## Important Disclosure

The data used in this project is fictional/synthetic. Any patterns, recommendations, or interpretations are demonstrations of analytical workflow and should not be treated as findings about a real employer, workforce, or employee population.
